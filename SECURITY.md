# Security policy

ekPanel controls servers with root privileges, so security reports come first.

**Never report a vulnerability in a public issue.** Report it privately:

- with GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability")
  on the affected repository, where it is available;
- or by email to **ekpanelbd@gmail.com** with "Security" in the subject.

Tell us what an attacker can do and what they need first, how to reproduce it, and the
versions. We aim to answer within 3 days and to fix critical problems within 14 days, and we
credit reporters unless they prefer otherwise. Each repository may have more details in its
own `SECURITY.md`.
