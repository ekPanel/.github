# Getting help

- **Documentation:** https://ekpanel.github.io/ekPanel-docs/ (English and বাংলা): installing,
  every feature, troubleshooting and a FAQ.
- **Bugs and ideas:** open an issue in the repository it is about, using its template.
- **Questions:** GitHub Discussions, once the main repository is public. Until then, email
  ekpanelbd@gmail.com.
- **Security problems:** never in public. See the security policy of the repository, or
  email ekpanelbd@gmail.com with "Security" in the subject.

ekPanel is made by volunteers. Clear reports with steps, versions and logs (with passwords
and keys removed) get answers fastest.
