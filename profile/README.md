<p align="center"><b>One panel. Your whole hosting.</b><br>এক প্যানেলে পুরো হোস্টিং</p>

**ekPanel** is an open-source hosting control panel for your own servers: classic web
hosting (like cPanel and aaPanel), Docker apps and Git deploys (like Coolify), email and DNS,
in one modern panel that speaks your language. **ek** (এক) is Bangla for "one".

- **Websites:** PHP 7.4 and 8.1–8.5 side by side, free HTTPS, a file manager, SFTP and FTP, redirects,
  cron jobs, logs and traffic charts
- **WordPress and PHP apps:** one-click WordPress with safe updates, staging and hardening;
  Joomla, Drupal, Moodle and Laravel
- **Apps:** any Docker image or Compose file, Git deploys with rollbacks and pull request
  previews, and a catalogue of one-click services
- **Data:** MariaDB and PostgreSQL, encrypted backups to S3-compatible storage
- **Email and DNS:** mailboxes and webmail; DNS at Cloudflare or on your own name servers with
  DNSSEC, with records made for you
- **Security:** firewall, CrowdSec, malware scans, country blocking, two-factor sign-in
- **Hosting business:** customers and packages with kernel-enforced limits, many servers,
  alerts by email, Telegram, Discord, Slack and webhooks
- **English and বাংলা** from day one, ready for more languages
