<p align="center"><b>One panel. Your whole hosting.</b><br>এক প্যানেলে পুরো হোস্টিং</p>

**ekPanel** is an open-source hosting control panel: classic web hosting (like cPanel and
aaPanel), Docker apps and Git deploys (like Coolify), and later email and DNS, in one modern
panel that speaks your language. **ek** (এক) is Bangla for "one".

- Websites with PHP 7.4–8.5, free HTTPS, a file manager and SFTP, one-click WordPress
- MariaDB and PostgreSQL, encrypted backups to S3, cron jobs, logs and traffic charts
- Docker apps and a catalogue of one-click services (Nextcloud, Ghost, n8n, Gitea…)
- Customers and packages with real memory and CPU limits, a web terminal, alerts
- English and বাংলা from day one, ready for more languages

> ekPanel is in early development and not ready for production hosting yet. The code will be
> published here under the AGPL-3.0 licence.
