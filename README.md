# .github

Shared files for the [ekPanel](https://github.com/ekPanel) organisation:

- `profile/README.md`: the organisation's profile page
- `CODE_OF_CONDUCT.md`, `SUPPORT.md`, `SECURITY.md`: used by every ekPanel repository that has
  none of its own
- `.github/ISSUE_TEMPLATE/` and `.github/PULL_REQUEST_TEMPLATE.md`: the same, for issues and
  pull requests
